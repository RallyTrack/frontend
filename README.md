# RallyTrack Frontend

RallyTrack는 배드민턴 경기 분석 및 기록 관리를 위한 웹 서비스입니다.  
본 저장소는 RallyTrack 프로젝트의 **프론트엔드** 레포지토리입니다.

## 🛠 Tech Stack

- **Framework**: React
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: CSS / HTML
- **Package Manager**: npm


## 📂 Project Structure

FrontEnd/
 ┣ public/ 이미지 파일 첨
 ┣ src/
 ┃ ┣ components/
 ┃ ┣ styles/
 ┃ ┣ App.tsx
 ┃ ┗ main.tsx
 ┣ index.html

 ┣ tsconfig.json
 ┗ vite.config.ts
